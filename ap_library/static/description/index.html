📚 Library Management System

A complete, production-ready Odoo module for managing books, borrowing history, conflict resolution, and automated email reminders.

✅ Odoo 16 / 17 📦 Version 1.0 🏢 Community & Enterprise ⚖️ OPL-1 License

🌟 Key Features

📖 Book Catalogue

Manage books with cover images auto-fetched from OpenLibrary API, ISBN uniqueness constraints, Many2many authors, categories, copy count and real-time availability flag.

📋 Booking History

Full lifecycle — Draft → Pending → Approved → Returned / Rejected — with chatter, activity mixin, computed day-count and automatic sequence numbering.

⚔️ Conflict Detection

On approval, overlapping bookings are detected. If all copies are occupied, a wizard opens listing conflicts and offers available date slots to notify the borrower.

🎲 Demo Data Loader

One-click server actions to populate 20 realistic books with live cover art, categories, and 10 historical bookings spanning various statuses.

🗂️ Category System

Hierarchical categories with parent-child support, cover images, and a computed book count. Drill into category books directly from the kanban card.

🔔 Automated Emails

3 email templates: booking confirmation with PDF attachment, librarian status-update notification, and overdue return reminder grouped per customer.

📄 PDF Reports

QWeb-generated booking history and book-detail reports available as one-click downloads and auto-attached to outbound confirmation emails.

🔐 Role-Based Access

Three security groups — Admin, Librarian, User — with fine-grained record rules, group-restricted buttons and context-aware field defaults.

① Book Catalogue — List View with availability, ISBN, authors and cover images

② Booking History — Form View with status bar, approve/reject actions and chatter

③ Booking Conflict Wizard — detects overlaps and offers available date slots

⚙️ Installation Guide

  1. Download & place the module
    cp -r wk_library_management /opt/odoo/custom_addons/
  2. Update addons path in odoo.conf
    addons_path = /opt/odoo/addons,/opt/odoo/custom_addons
  3. Restart Odoo server
    sudo systemctl restart odoo
  4. Go to Apps → Update App List → Search "Library Management" → Install
  5. Load demo data (optional): Library → Books → Action → Load Demo Books
  6. Configure SMTP: Settings → Technical → Outbound Mail Servers
📦 Dependencies: base, mail — no extra Python packages required beyond requests (standard in Odoo environments).
