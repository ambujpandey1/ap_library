01
Module Overview

Everything a modern library needs

📖

Book Catalogue

Manage books with cover images auto-fetched from OpenLibrary, ISBN uniqueness constraints, authors (Many2many to res.partner), categories, copies count and real-time availability flag.

🗂️

Category System

Hierarchical categories with parent-child support, cover images, and a computed book count. Drill into category books directly from the kanban card via action_view_books.

📋

Booking History

Full lifecycle tracking — Draft → Pending → Approved → Returned / Rejected — with chatter, activity mixin, computed day-count, and automatic sequence numbering.

⚔️

Conflict Detection

On approval, overlapping bookings are detected. If all copies are occupied a wizard pops listing conflicts and offering available date slots to notify the user.

🔔

Automated Emails

Three email templates: booking confirmation with PDF attachment, librarian status-update notification, and overdue return reminder grouped per customer.

📄

PDF Reports

QWeb-generated booking history report and book-detail report, both available as one-click downloads and auto-attached to outbound emails.

🧙

Wizards

Three purpose-built wizards: Book Issue Request (user), Booking Conflict (admin), and Available Slot — each launched via smart window actions.

🔐

Role-Based Access

Three security groups — Admin, Librarian, and User — with fine-grained record rules, group-restricted buttons, and context-aware field defaults.

🎲

Demo Data Loader

One-click server actions to populate 20 realistic books (with live cover art from OpenLibrary), categories, and 10 historical bookings spanning various statuses.

03
Booking Lifecycle

Full booking workflow

1

User Requests

User clicks "Request Book" → wizard opens pre-filled with dates & user

2

Draft Created

Booking created with sequence no. Confirmation email with PDF sent automatically

3

Pending Review

Status moves to Pending. Librarian sees it in queue with chatter log

4

Conflict Check

On approval, overlap detection runs against all approved bookings for same book

5

Approved / Slot

If slots free → Approved & copy count decremented. Else → Conflict Wizard

6

Returned

Mark returned → copy incremented, availability restored, chatter updated

✦ ✦ ✦

Booking Status State Machine

Draft → Pending → Approved → Returned or Pending → Rejected

Getting Started

Installation guide

Download & Place the Module

Download the zip from the Odoo App Store and extract it into your Odoo addons path.

cp -r enhance_library /opt/odoo/custom_addons/

Update the Addons Path

Make sure your odoo.conf includes the custom_addons directory.

addons_path = /opt/odoo/addons,/opt/odoo/custom_addons

Restart Odoo Server

sudo systemctl restart odoo

Update App List & Install

Go to Apps → Update App List, search for "Library Management" and click Install.

Load Demo Data (Optional)

Navigate to Library → Books, open Action menu → Load Demo Books. Do the same for categories and bookings.

Configure Outbound Mail

Go to Settings → Technical → Outbound Mail Servers and configure your SMTP server so that booking confirmation and reminder emails are delivered.

📦 Dependencies

This module requires mail (for chatter & email templates) and base. No third-party Python packages beyond requests (used for OpenLibrary cover art fetching — standard in most Odoo environments).

Module Anatomy

File structure & location guide

📍 Where to place index.html for the Odoo App Store

Place this file at: enhance_library/static/description/index.html
Odoo's App Store renderer automatically reads static/description/index.html as the module's description page. Any images referenced inside it should go in static/description/ as well (e.g. images/banner.png). The __manifest__.py key "images": ["static/description/icon.png"] controls the listing thumbnail.

enhance_library/static/description/index.html ← this file
